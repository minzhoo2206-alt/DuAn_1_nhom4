# FOURTECH FRONT-END
Chỉ gồm HTML, Tailwind CSS và JavaScript thuần. Không có PHP, PDO, MySQL hoặc backend.

## Chạy
- Mở `index.html` trực tiếp bằng trình duyệt, hoặc dùng VS Code Live Server.
- Tailwind đang dùng CDN nên cần Internet.

## Trang
- `index.html`: Trang chủ
- `products.html`: Danh sách điện thoại + lọc thương hiệu/giá
- `product-detail.html`: Chi tiết sản phẩm
- `cart.html`: Giỏ hàng (LocalStorage)
- `checkout.html`: Giao diện thanh toán
- `login.html`, `register.html`: Đăng nhập/đăng ký (giao diện)
- `account.html`, `orders.html`: Tài khoản và lịch sử đơn
- `contact.html`: Liên hệ
- `admin/index.html`: Tổng quan quản trị
- `admin/products.html`, `admin/categories.html`, `admin/orders.html`, `admin/users.html`

## Lưu ý
Đây là front-end. Các form đăng nhập, đăng ký, thanh toán và nút CRUD quản trị chỉ là giao diện minh họa, chưa xử lý dữ liệu trên máy chủ.
